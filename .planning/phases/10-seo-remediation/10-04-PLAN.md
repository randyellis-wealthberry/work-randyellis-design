  <name>Checkpoint: Live SEO verification</name>
  <what-built>
All SEO remediation work from Phase 10 has been deployed to production:
- Plan 10-01: robots.txt allows /_next/, permits AI crawlers, sitemap has lastModified
- Plan 10-02: Service worker kill-switch active, PWA artifacts removed
- Plan 10-03: Server-rendered Person/WebSite/Organization schema, LocalBusiness/FAQ deleted

This checkpoint verifies the changes work correctly in the live production environment per D-16 (mandatory verification step).
  </what-built>
  <how-to-verify>
**1. Fetch live robots.txt:**
```bash
curl https://work.randyellis.design/robots.txt
```

Verify output:
- Contains `Disallow: /private/`, `/admin/`, `/api/`, `/drafts/` (4 entries only)
- Does NOT contain `Disallow: /_next/`
- Does NOT contain user-agent blocks for GPTBot, CCBot, ChatGPT-User, anthropic-ai, Claude-Web
- Contains `Sitemap: https://work.randyellis.design/sitemap.xml`

**2. Fetch live sitemap.xml:**
```bash
curl https://work.randyellis.design/sitemap.xml
```

Verify output:
- Contains `<lastmod>` tags for home, /projects, /about, /blog, /metis (static pages)
- Contains `<lastmod>` tags for all project URLs (e.g., /projects/growit, /projects/ohplays, etc.)
- Contains `<lastmod>` tags for all blog post URLs
- All lastmod values are ISO 8601 dates (YYYY-MM-DD format)

**3. Google Rich Results Test:**

Test these URLs:
- Home: https://work.randyellis.design/
- One project: https://work.randyellis.design/projects/growit
- One blog post: https://work.randyellis.design/blog/{any-slug}

For each URL:
1. Go to https://search.google.com/test/rich-results
2. Enter the URL and click "Test URL"
3. Wait for Google to fetch and render the page
4. Check for:
   - **Home page:** Person, Organization, WebSite schemas detected (3 types)
   - **Project page:** Person, Organization, WebSite, CreativeWork, Breadcrumb schemas detected (5 types)
   - **Blog page:** Person, Organization, WebSite, Article schemas detected (4 types)
   - Zero errors for LocalBusiness or FAQPage (both deleted)
   - Zero errors for invalid properties (addressLocality, openingHours, offeredThrough, etc.)
   - All sameAs URLs use x.com, not twitter.com

**4. Search Console verification:**

1. Log into Google Search Console at https://search.google.com/search-console
2. Confirm the property `https://work.randyellis.design` exists
3. Navigate to Sitemaps section
4. Verify `https://work.randyellis.design/sitemap.xml` is submitted
5. Check status: should show "Success" (green) or "Couldn't fetch" if too recent (will resolve after first crawl)

**5. Service Worker verification (returning visitor test):**

1. Open Chrome DevTools
2. Go to Application tab → Service Workers
3. Load https://work.randyellis.design/
4. Observe:
   - Kill-switch SW activates briefly (shows in panel)
   - Cache Storage is cleared (all caches deleted)
   - Service Workers panel becomes empty (SW unregistered itself)
5. Refresh the page
6. Confirm: No service worker registered, no caches present

**6. Document results:**

Create `.planning/phases/10-seo-remediation/10-LIVE-VERIFICATION.md` with:
- robots.txt fetch output (first 20 lines)
- sitemap.xml fetch output (first 50 lines showing lastmod tags)
- Rich Results Test outcomes for all 3 URLs (valid schemas detected, error count)
- Search Console confirmation (property exists, sitemap submitted, status)
- Service worker verification outcome (kill-switch activated and unregistered)
- Any issues found and their resolution

If any verification fails (e.g., /_next/ still blocked, LocalBusiness errors, sitemap missing lastmod), document the issue and investigate before marking complete.
