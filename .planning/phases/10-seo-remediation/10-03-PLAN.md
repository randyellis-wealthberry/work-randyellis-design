<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Search engine crawlers → structured data | Crawlers parse JSON-LD in initial HTML; server-rendered schema is more reliable than client-hydrated |
| User browser → dangerouslySetInnerHTML | Inline JSON-LD bypasses React escaping; must escape `<` to prevent XSS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-07 | Tampering | JSON-LD XSS via unescaped `<` | mitigate | Use `.replace(/</g, '\\u003c')` in dangerouslySetInnerHTML per Context7 pattern (10-RESEARCH.md Pitfall 1) |
| T-10-08 | Spoofing | Fabricated LocalBusiness schema signaling invalid entity | mitigate | Delete LocalBusiness entirely per D-02; Google penalizes fabricated markup |
| T-10-09 | Information Disclosure | Chameleon Collective URL revealing partnership details | accept | URL is public if valid; checkpoint verifies it resolves before including in schema |
</threat_model>
