Replace the entire contents of `public/sw.js` with a kill-switch script that:

1. On install: calls `self.skipWaiting()` to activate immediately
2. On activate: clears all caches via `caches.keys()` and `caches.delete()`, then calls `self.registration.unregister()`, then `self.clients.claim()`
3. Includes no fetch handler — requests go directly to network after unregistration

Use the implementation pattern from 10-RESEARCH.md lines 617-649 (Service Worker Kill-Switch code example). The script should be ~30-40 lines including comments and console.log statements for debugging.

Key lifecycle sequence: returning visitor loads page → SW install event fires → skipWaiting() → activate event fires → clear all caches → unregister SW → claim clients → on next page load, no SW is registered.

This ensures any visitor who registered the stale Workbox SW (from the next-pwa era) gets it replaced and removed on their next visit.
