| 1 | 4px | Micro adjustments |

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Meta label | 12px (xs) | 400 | default | "My Role", "Key Decisions", field labels |
| Body | 16px (base) | 400 | relaxed (1.625) | Narrative text, decision rationale |
| Decision statement | 16px (base) | 500 | relaxed (1.625) | Decision declaration (what was chosen) |
| TOC heading | 14px (sm) | 600 | default | "On this page" label |
| Decision title (h3) | 20px (xl) | 600 | default | Individual decision heading |
| Reflection heading (h2) | 24px (2xl) | 700 | default | Closing reflection |
| Section heading (h2) | 30px (3xl) | 700 | default | "My Role", "Key Decisions" |

**Font families:**
- Sans: Geist (var(--font-geist)), system-ui fallback
- Mono: Geist Mono (var(--font-geist-mono)), ui-monospace fallback

**Typography patterns:**
- Meta labels: `text-xs tracking-wide uppercase` in muted-foreground
- Section headings: ScrambleSectionTitle component (h2/h3) with hover scramble effect
- Body prose: `text-base leading-relaxed` in foreground or muted-foreground

**Note:** Template specifies "exactly 2 weights" but Phase 6 implementation uses 4 (400, 500, 600, 700) to establish proper typographic hierarchy across decision components. Primary weights: 400 (body) + 600/700 (headings).

**Source:** component implementation + CONTEXT.md D-12 (existing primitives only)

## Accessibility Contract

| Pattern | Implementation | Source |
|---------|----------------|--------|
| Section landmarks | `role="region"` + `aria-labelledby="{id}-heading"` | D-10 (carried from Phase 5 D-12) |
| Heading hierarchy | h2 for sections, h3 for decisions | Claude's Discretion from CONTEXT.md |
| Unique IDs | `{sectionId}-heading`, `{sectionId}-decision-{N}-heading` | decision-callout.tsx, role-narrative-section.tsx |
| Semantic headings | ScrambleSectionTitle with `as` prop, no role="button" | D-11 (fixed in Phase 6) |
| Keyboard navigation | Native anchor links in TOC, no custom scroll behavior | case-study-toc.tsx lines 20-21 |
| Focus indicators | `focus-visible:ring-2` on TOC links | case-study-toc.tsx line 48 |

**No scrollspy:** Deliberately omitted (CONTEXT.md deferred idea). Scroll listener would run every frame for purely decorative highlight; native anchors already provide keyboard/screen reader jump targets.

**Verified:** `role="button"` count is 0 across case-study pages (D-11 regression check, verified in Phase 6 per CONTEXT.md D-17)

## Design Constraints (Phase 6 Specific)

### No-AI-Slop Directive (D-16 from Phase 5, enforced in Phase 6)

**Allowlist (what Phase 6 CAN use):**
- Badge primitive (components/ui/badge.tsx) — variant="outline" only
- ScrambleSectionTitle (components/ui/scramble-section-title.tsx) — the platform's section-heading language
- @tailwindcss/typography prose classes — available but not used in Phase 6
- Motion primitives (in-view, text-effect, scroll-progress, glow-effect) — available but not used in Phase 6

**Ban list (what Phase 6 CANNOT use):**
- lucide-react icons in narrative components (generic AI slop pattern)
- Card wrapper for DecisionCallout (nesting cards flattens visual hierarchy)
- New color/spacing/typography tokens (must use existing CSS variables)
- Amber accent color (reserved exclusively for Live Product status badge)
- Decorative stock imagery
- Uniform template fill (alternatives-considered and leadership-signal callouts only where genuinely applicable per CNT-08, not as mandatory template slots)

**Rationale (from CONTEXT.md specifics):**
> "I want these case studies to not be AI slop, it should be unique using the platform design language and components."

**Verification:** All narrative components use only allowlisted primitives. DecisionCallout uses `bg-muted/30` background instead of Card wrapper (D-06). No lucide icons appear in any narrative component. No amber accent usage (grep verified).

**Source:** CONTEXT.md D-12, D-13, D-16 + specifics section
