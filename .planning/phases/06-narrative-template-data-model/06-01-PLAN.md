## Established Patterns

From codebase conventions:
- Server/client split: `app/projects/[slug]/page.tsx` (server) imports `project-detail-client.tsx` (client)
- Props-only rendering: all data from props, no hardcoded project-specific strings
- Graceful degradation: early return when data missing (`if (!data) return null;`)
- Path aliases: `@/*` → root directory
- Design language: ScrambleSectionTitle for all section headings (39 uses site-wide)
- Accessibility: section id + role="region" + aria-labelledby="{id}-heading" contract

From Phase 5:
- D-12: Accessibility contract must be preserved (section landmarks with proper ARIA)
- D-16: No-AI-slop directive enforced via allowlist (Badge, ScrambleSectionTitle, @tailwindcss/typography) and bans (lucide icons in narrative, Card wrapper for DecisionCallout, new tokens, amber accent outside Live Product badge)

## Project Instructions

From CLAUDE.md:
- Verification order: `npm run lint` → `npx tsc --noEmit` → `npm test` (build is NOT a validation gate)
- Path aliases: `@/*` resolves to project root
- TypeScript: strict mode, TSDoc for public APIs

## Design Constraints

From 06-CONTEXT.md D-12, D-13:
- **Allowed primitives:** Badge (variant="outline"), ScrambleSectionTitle (h2/h3), @tailwindcss/typography (prose classes), motion primitives (if needed)
- **Banned patterns:** lucide icons in narrative components, Card wrapper for DecisionCallout, new color/spacing/type tokens, amber accent (reserved for Live Product badge only)

From 06-UI-SPEC.md:
- Spacing: strict 4-point multiples only (4px, 8px, 12px, 16px, 20px, 24px, 32px, 48px, 64px)
- Typography: 4 sizes (14px meta, 16px body, 24px decision titles, 30px section headings), 2 weights (400, 700)
- Color: zinc palette base, no accent usage in narrative components
