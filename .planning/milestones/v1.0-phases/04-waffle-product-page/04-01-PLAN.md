Decision note (conscious D-08 deviation): D-08 says "introduce as a scoped accent token", but this phase uses literal `amber-600`/`amber-500` Tailwind utilities instead. Rationale: Tailwind v4's built-in amber values match D-08's OKLCH tokens digit-for-digit (`--color-amber-600: oklch(66.6% 0.179 58.318)`, `--color-amber-500: oklch(76.9% 0.188 70.08)` — verified in `node_modules/tailwindcss/theme.css`), and the repo's semantic-token path is broken (no `@config` directive in `app/globals.css`, so custom CSS-variable tokens compile to nothing — see 04-UI-SPEC Constraint). Literal utilities are the reliable, numerically identical equivalent; this is a deliberate decision, not an accident.
</objective>
