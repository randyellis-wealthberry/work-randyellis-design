## Milestone Summary

### Key decisions

- **One shared `CaseStudyTemplate` instead of four separate narrative
  components.** Phases 6-7 specified `DecisionCallout` / `CaseStudyTOC` /
  `ReflectionBlock` / `RoleNarrativeSection`. What shipped is a single
  `components/case-study/case-study-template.tsx` plus `diagrams` and
  `section-chrome`, shared by all five standalone project pages. Stronger
  structural consistency than the original plan, and it pulled waffle in too.
- **Typed data model over MDX.** Narrative lives in `lib/data/projects.ts` as
  `decisions[]{title, decision, rationale, outcome}` + `roleNarrative`, keeping
  every claim greppable for credibility audits.
- **Deck-gate removed 2026-08-15.** The deck became an advisory reference rather
  than a blocking source-of-truth; Randy's firsthand account became the source,
  with CRED-07 as the guardrail.
- **Client business figures withheld on Echo** per CRED-08 — process and design
  work narrated, commercial specifics left with the client.
- **DNS over meta tag for Search Console verification** — a token in
  `lib/metadata.ts` would sit in the path of v3.0's planned metadata sweep.

### Known issues carried forward

- **CRED-07 sitewide gap.** SITE-01 (`2.5M+`), SITE-03 (`$50M`), SITE-04 (`800+`)
  were ruled `Unbacked` by FND-03's own deck audit and remain live across five
  surfaces. Phase 9 aligned the `$50M` *wording* rather than removing the claim.
  Scoped into v3.0 as CRED-10..12. "4 Design Awards" shares the same component
  and **is** backed — it must survive remediation.
- **Blog Article structured data** emits bare dates (`2025-07-21`) with no time
  or timezone, and no `image`; `Paywalled Content` is detected on a post that is
  not paywalled.
- **Standing DNS dependency:** the apex `google-site-verification` TXT record now
  carries Search Console ownership. Removing it forfeits the property history.

### Process debt

- **Phases 07 and 08 were executed entirely outside GSD** — no plan, summary or
  phase directory was ever committed, so `roadmap analyze` and the milestone
  pre-flight both reported incorrectly. Compensated by direct-codebase audit, the
  same way v1.0 handled phases 1-3.
- **`/services` and the retainer funnel** appear in neither ROADMAP nor
  REQUIREMENTS — built ad-hoc, and they now own the metadata description and the
  primary conversion path on a site chartered for hiring managers.
- **`automation-results.json`** recorded a false negative in Phase 10 by
  text-matching Google's login dialog as a structured-data error.
